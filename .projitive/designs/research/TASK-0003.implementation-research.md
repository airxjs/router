## Code Architecture and Implementation Findings

- **No UI components exist**: The library is a pure logic layer for the airx component framework
- **Public API surface** (`source/index.ts`):
  - Components: `Router` only (logic component, no visual rendering)
  - Hooks: `useRouter()` — returns `History` instance
  - Types: `Route`, `PathRoute`, `RedirectRoute`, `RouteComponentProps`
  - Utilities: `createBrowserHistory`, `createHashHistory`, `createMemoryHistory`
- **Interaction is purely programmatic**: Navigation via `history.push()`, `history.replace()`, etc.
- **Zero visual tokens**: No colors, typography, spacing, or design tokens — this is intentional
- **Accessibility deferred to host app**: Applications using airx-router must implement their own a11y
